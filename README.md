# 매물 데스크 (Listing Desk)

한국 공인중개사를 위한 Druve 에이전트예요. 매물 메모를 붙여넣으면 광고 초안과 규정 점검표를, 고객 문자를 붙여넣으면 답장 초안을, 계약 소식을 붙여넣으면 마무리 체크리스트를 만들어 줘요.

- 사실은 코드가 다루고(숫자, 단위, 빠진 필수 항목), 모델은 문장만 써요. 메모에 없는 사실은 지어내지 않고 `[확인 필요]`로 남겨요.
- 모든 결과는 초안이에요. 최종 확인과 책임은 사장님에게 있어요. 법률이나 세금은 판단하지 않아요.
- 규정 근거는 `RULES.md`에 조문과 확인한 날짜와 함께 있어요.

한 파일(`index.mjs`)로 되어 있고 `@druve/cli/providers`만 불러와요. 테스트: `npm test`.
